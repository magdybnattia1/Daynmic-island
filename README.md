# Dynamic Island Android

مشروع أولي لتطبيق كبسولة عائمة على أندرويد.

## المزايا الحالية
- كبسولة سوداء أعلى الشاشة.
- تتغير الرسالة إلى "جاري الشحن" عند توصيل الشاحن.
- تشغيل وإيقاف من واجهة التطبيق.
- بناء APK تلقائيًا عبر GitHub Actions.

## بناء APK على GitHub
1. أنشئ مستودعًا جديدًا على GitHub باسم `DynamicIslandAndroid`.
2. ارفع كل ملفات هذا المشروع إلى المستودع (مع الحفاظ على المجلدات).
3. افتح تبويب **Actions** وانتظر انتهاء مهمة **Build Android APK**.
4. افتح المهمة الناجحة، ثم حمّل ملف `DynamicIsland-debug-apk` من قسم **Artifacts**.

## ملاحظات
- عند أول تشغيل، اسمح للتطبيق بالظهور فوق التطبيقات.
- هذا إصدار تأسيسي؛ إشعارات التطبيقات والتحكم بالموسيقى والمكالمات وتحديد موضع الكاميرا بدقة ستضاف في المراحل التالية.
- موضع الكبسولة الحالي أعلى منتصف الشاشة وقد يحتاج ضبطًا حسب موديل الهاتف وفتحة الكاميرا.
