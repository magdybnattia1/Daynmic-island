# Dynamic Island Pro

Native Android app project for a floating Dynamic Island-style capsule.

## Included
- Floating capsule overlay.
- Battery percentage and charging state.
- App notification previews, including WhatsApp notifications exposed by Android.
- Incoming and ongoing call state after granting phone-state permission.
- Media session controls: previous, play/pause, next.
- Capsule color and size customization.
- GitHub Actions workflow that builds a debug APK artifact.

## Device setup
1. Install the APK.
2. Open the app and grant Display over other apps.
3. Enable Notification access for Dynamic Island Pro to receive app alerts and use media controls.
4. Grant Phone permission to show call state.
5. Tap Start Dynamic Island.

Some Android manufacturers restrict background overlays or notification details. The app only displays notification text that Android makes available to notification listeners.
